Pixel Identification in an Image Using Grover's Algorithm

Image → find the darkest pixel → quantum representation → Grover search → |0000000000⟩ → pixel (0,0) = 0. Click a pixel.

02What are we searching, and what must we represent?

We want the darkest pixel (smallest intensity). A quantum computer only works on quantum states, so the image needs two registers: which pixel (position) and how bright (intensity). Click the position qubits.

POSITION 2 qubits  

INTENSITY 8 qubits

2 qubits → 4 positions. 8 qubits → 256 brightness levels (0–255). Total 10 qubits.

2² = 4 positions; 2⁸ = 256 levels; 10 qubits span a 2¹⁰ = 1024-dimensional Hilbert space (that is not 1024 pixels).

03NEQR: tie each position to its intensity

NEQR writes the brightness of every pixel in binary into the intensity register, conditioned on the position. Click a row or a term.

The state is one joint quantum state of position–intensity correlations — not four classical values you can read all at once.

Normalisation: four equal orthogonal terms ⇒ amplitude 1/√4 = ½. Written |intensity⟩|position⟩. The registers are correlated in a non-separable (entangled) way for distinct intensities.

04Position superposition

Two Hadamard gates turn |00⟩ into an equal-amplitude superposition of the four positions. Step through it.

We have created the possible pixel positions, but we have NOT encoded the intensity values yet.

05Intensity register

Pick a brightness. Only the qubits that correspond to a binary 1 will ever need to be flipped.

06Controlled encoding: the CCX gate

A CCX (Toffoli) has two controls and one target. Click a control pattern.

07Deep dive: how does the circuit encode ONE particular pixel?

Select another pixel in the first section to encode a different one. Use Next to go one gate at a time; click any gate to inspect it.

08Why the other pixels are not affected

All four branches are present at once. The temporary X relabels them; then the CCX is applied.

09Complete NEQR state

Repeat the same recipe for all four pixels. Press Auto or step through.

10Grover oracle

Now we have the image. How do we search it? The darkest pixel has intensity 0 at (0,0), so the target is |0000000000⟩ (written |intensity⟩|position⟩).

The oracle changes PHASE, not probability. Uf = I − 2|m⟩⟨m| ; Uf|x⟩ = (−1)f(x)|x⟩.

11Grover diffuser

H→X→phase flip on |1…1⟩→X→H

This performs inversion about the mean: each amplitude a becomes 2ā − a. The oracle marked the target with a phase; the diffuser converts that phase difference into amplitude amplification. D = 2|s⟩⟨s| − I.

12Amplitude amplification

Repeat oracle + diffuser. The target grows; other states shrink together. Watch the vertical scale: it is rescaled so small amplitudes stay visible.

θ = arcsin(1/√N), P(t) = sin²((2t+1)θ), kopt ≈ (π/4)√N. Two reflections make a rotation by 2θ per iteration. Too many iterations overshoot.

13Final measurement

Measuring gives one classical string per shot, sampled with probability a². Try measuring before and after amplification.

Press Measure.

Image → Position → NEQR → Oracle → Diffuser → Measurement → Pixel

YOU HAVE JUST COMPLETED A QUANTUM IMAGE SEARCH

15Research notes

Researcher's Note. The current project demonstrates the integration of NEQR-style image representation with Grover amplitude amplification for a marked target state. The current implementation does not yet implement a fully coherent quantum minimum-finding algorithm.
A complete minimum finder would need: a reversible comparison, minimum-finding logic, an oracle constructed from the encoded intensities, and no classical extraction of the minimum beforehand. This is a natural research extension, not a hidden flaw.

What this app shows, honestly

  • The target string is supplied (the minimum is found classically here); the oracle does not read it from the NEQR state.
  • As in the modernised reference code, the Grover stage runs over all 2¹⁰ strings with |0000000000⟩ marked; the NEQR encoding is demonstrated alongside it.
  • Thesis simulation: 8183 of 8192 shots on the target (≈ 99.89%) — a sampled estimate, not an exact probability.
  • No practical quantum advantage is claimed for 2×2 images. State preparation, oracle cost and measurement must be counted in any end-to-end claim.
  • Bit order: strings are shown as |q7…q0⟩|q9 q8⟩. Qiskit often prints bitstrings reversed — always state the convention.

Next steps: a reversible 8-bit comparator, a threshold oracle, a minimum-finding strategy, larger images, resource and noise studies, hardware runs, and classical baselines.

Tip: everything here is interactive. Click pixels, gates, table rows and kets, and use the Playground to try your own 2×2 image. Nothing is sent anywhere; it all runs in your browser.
